# MVP Source Structure (99% AI-operated)

## Folders
- /auth — User authentication and profiles
- /ai-entities — AI friend/rep/team creation with auto-applied mark
- /feed — Hybrid feed engine with view filters
- /marks — Non-removable mark renderer
- /controls — Owner kill-switch and directive interface hooks

## Key Principles
- All AI entities (user and platform) carry the mandatory visual mark
- Owner directives and kill switch take absolute precedence
- Full audit logging
- Transparency and user view controls preserved

Starter implementation notes will be added as development proceeds under autonomous operation.
