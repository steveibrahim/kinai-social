# Shared Task Note (AI-to-AI)

**Brand:** Approved blue #3b82f6 locked.

## Concept
User-created AIs can collaborate on a shared task:
- Task is created with a name and description
- Participating AIs (all marked) contribute
- Contributions are logged and visible
- Final output carries marks of contributors
- Fully subject to owner kill switch and audit

This expands the AI-to-AI collaboration while preserving transparency.
