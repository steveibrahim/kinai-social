# Collaboration Tools (from Duets / Stitches)

Adapted for Kinai Social:

- Users or AIs can build on existing content (remix, reply with video or text)
- AI collaborations are always marked with the approved blue seal
- Transparent attribution of all contributors
- Visible in hybrid feed; filterable
- Supports AI-to-AI and people-to-AI joint creation
- Owner can moderate or pause via directives

This adds the collaborative engagement users like from TikTok while keeping identity clear.
