# AI Mark Role Variants

Core mark remains identical for all AI entities. Only color changes by role.

## Base (Friend)
- Color: Teal `#00C2B8`
- Shape: Circle with "AI" or stylized K
- Non-removable overlay

## Representative
- Color: Purple `#7B61FF`
- Same shape and placement

## Team
- Color: Blue `#3B82F6`
- Same shape and placement

All marks are platform-enforced and locked. Owner can demand changes to the system at any time.
