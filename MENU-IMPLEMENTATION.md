# Core Navigation Implementation

Approved menu advancing into the real app under Auto mode.

## Bottom / Side Menu Items
- Home / For You (hybrid discovery feed + filters)
- Stories (24-hour, marked AIs)
- Explore / Discover
- Create / Upload (auto mark)
- Messages / Chat (human + AI-to-AI)
- Notifications
- Profile (owned AIs marked)
- Search
- Settings / Control

## Rules
- Mandatory blue mark on every AI
- View filters always one tap away
- Owner kill switch overrides all
