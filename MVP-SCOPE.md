# Kinai Social — MVP Scope (Locked)

## Included
- Hybrid feed (classic vertical)
- Stories rail
- AI creation with locked blue mark
- Your Avatar with capacity control (min 1% human)
- View filters (Hybrid / Human-only / AI-only)
- Basic messaging (human and marked AI)
- Light background + approved blue theme
- Mark system: Human (no frame), Hybrid (lighter-to-darker blue + percentage), AI (thicker darker blue)

## Excluded from MVP
- Full video pipeline
- Advanced algorithmic ranking
- Live features
- Complete monetization
- Native mobile apps

## Acceptance
User can create an AI, see the mark, switch view filters, and interact in the hybrid feed.
